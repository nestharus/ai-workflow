# Landing Page Messaging Strategy

## Positioning Challenge

This product is fundamentally different from all competitors. Cursor/Windsurf
help you write code faster. Bolt/Replit/v0 let you build by typing. This
product ensures your AI-generated code is **actually correct, complete, and
well-organized** — without requiring you to be an engineer.

Every competitor focuses on Day 1 (creation speed). This product owns Day 2+
(maintenance, quality, evolution). That gap is wide open.

BUT: Vibe coders don't know they have a quality problem. They only know
"things break" and "debugging sucks." The narrative must start with pain
they recognize, then name the problem they can't articulate.

---

## Core Narrative Arc

### 1. Hook: Recognition ("I've been there")
Start with the feeling vibe coders already have — the frustration of
AI-generated code breaking in mysterious ways.

### 2. Name the Problem: Revelation ("Oh, THAT'S why")
Explain what's actually going wrong — in plain language. AI drops details.
AI takes shortcuts. No one checks the AI's work. Your code drifts from
what you asked for.

### 3. Show the Solution: Hope ("There's a better way")
Multiple AI specialists checking each other. Code earns its way to
production. Every requirement tracked. Failures fixed at the root, not
patched.

### 4. Make It Real: Clarity ("Here's how it works")
Simple 3-step explanation. Visual workflow. Feature highlights.

### 5. Close: Action ("Join the waitlist")
Low-friction CTA with clear value proposition.

## FAQ / Objection Handling

**"Is this just another Cursor/Copilot?"**
No. Those are AI coding assistants — one AI writes code and you review it.
This is a quality pipeline — multiple AIs write, review, and organize code
through gates before it ever reaches you.

**"Do I need to know how to code?"**
No. You write specs in plain language. The system handles implementation,
review, and quality control.

**"What if I already use Cursor/Copilot/etc?"**
This works alongside your existing tools. It doesn't replace them — it adds
quality control on top. (Workflow engine integrates with Claude Code,
Cursor, Windsurf, etc.)

**"Is my code private?"**
The free local version never sends code anywhere except to the AI APIs you
configure. Your code stays on your machine.

**"When does it launch?"**
We're building the prototype now. Join the waitlist to be first when we
launch.

## Tone & Voice Guidelines

- **Plain language**: No jargon. If a term requires explanation, either
  explain it or replace it.
- **Confident but not arrogant**: "This works" not "This is the best."
- **Problem-first**: Lead with pain, then solution. Never just features.
- **Honest about limitations**: "We're building this. Join us early."
  This builds more trust than pretending the product is finished.
- **Respectful of the audience**: Vibe coders are creative and capable.
  They're not "bad developers" — they're people using new tools in new ways.
  The system helps them do it better, not fixes their mistakes.
