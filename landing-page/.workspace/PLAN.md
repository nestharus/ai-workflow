# Landing Page Project Plan

## Goal
Create a landing page for the Spec Manager product targeting "vibe coders" —
people who use AI to code but don't deeply understand software engineering.
They recognize problems from debugging sessions but may not know *why* things
break or that solutions exist.

## Product Understanding
- **Spec Manager**: AI-powered specification management that ensures code
  matches intent through a multi-layer promotion pipeline
- **Workflow Engine**: The runtime environment spec manager operates in —
  custom workflows, model selection, transparency, extensibility
- **Key Value**: "VS Code for the AI era" — flexibility, control, transparency

## Target Audience: "Vibe Coders"
- Use AI (Copilot, Claude, ChatGPT) to write code
- Don't fully understand architecture, testing, or specification
- Problems they recognize: debug sessions, code that doesn't work, AI
  generating wrong things, losing context, rework loops
- Problems they DON'T recognize: spec drift, missing governance, no
  promotion gates, untested assumptions

## Primary CTA: Join Waitlist
- Need a database (SQLite or simple backend) for email collection
- Low commitment: just email, no credit card

## Business Model (for page context)
- Free local version for power users
- $15/mo hybrid (remote + local, own AI keys)
- Fully remote version (easiest, most expensive)

## Constraints
- No UI exists yet — can't capture product screenshots
- Can show workflow diagrams, conceptual mockups, architecture visuals
- Limited effectiveness now; will be improved later
- Must communicate value to non-technical users

## Design Direction (from feedback1.md analysis)
Best fit: **Playbook 4 — "High-tech immersion"** with elements of
**Playbook 2 — "Scroll narrative product tour"**
- Dark theme with glow accents (AI/devtools category)
- Scroll-driven storytelling to explain complex product simply
- Bento grid for feature showcase
- Subtle animations, not overwhelming
