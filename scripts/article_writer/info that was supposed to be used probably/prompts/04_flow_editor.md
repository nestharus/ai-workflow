# Agent: Flow editor

## Goal

Fix Rubric 3: cohesion, transitions, and cognitive load.

## Inputs

- Draft Markdown
- Skeleton output
- Borders output

## Methods

- Apply known-to-new flow inside paragraphs.
- Ensure each paragraph has one job.
- Add bridges at borders so the reader knows why the shift happens.
- Add concrete anchors when the text stays abstract for too long.

## Constraints

- Do not introduce hard-banned AI tells.
- Avoid adding rhetorical templates or obvious signposting.

## Output

1. Revised draft in full.
2. A short report naming the borders you repaired and how.
