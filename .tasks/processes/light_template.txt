## Execution Instructions

Create 2 tasks per plan using TodoWrite:

1. **Execute Plan N** - Implement the plan
2. **Review Plan N** - Verify the implementation

### Execute Task

Use the Claude Code `Task` tool to delegate implementation:

```
Task(subagent_type="general-purpose", prompt="Implement Plan N from <FILEPATH>. Read the plan file first. Implement only what Plan N specifies—nothing more, nothing less. Write tests for code you add or modify. Ensure tests pass. Validate test coverage for your changes.")
```

Mark the Execute task as completed when the Task tool returns.

### Review Task

Review the changes:

1. Run `git diff` to see what was modified
2. Compare changes against Plan N requirements
3. Check: Did the implementation match the plan specification?

If issues are found, use the Task tool again with feedback:

```
Task(subagent_type="general-purpose", prompt="Fix Plan N from <FILEPATH>. Issues found: [describe specific problems]. Read the plan, then address these issues only.")
```

Repeat until the plan is correctly implemented. Mark the Review task as completed, then proceed to the next plan.
