# Projection Pin Template (System-Owned)

Pins may be embedded in non-authoritative projections (plan.md) to provide stable anchors.

Format (single line):

[@pin:<pin_id> target:<target_kind>:<target_id>]

Examples:

[@pin:PIN-0001 target:LIBRARY:LIB-0003]
[@pin:PIN-0312 target:ELEMENT:REQ-LIB-0003-0007]
