# Provenance Stamp Template (System-Owned)

This marker may be embedded in generated intermediate markdown only.
It must be stripped in final outputs.

Format:

<!-- @from:<patch_id> @modified:<patch_id_list> @atoms:<atom_id_list_or_ranges> -->

Examples:

<!-- @from:p0001 @modified:p0002,p0005 @atoms:ATOM-F0001-R0001-L0001,ATOM-F0001-R0001-L0002 -->
