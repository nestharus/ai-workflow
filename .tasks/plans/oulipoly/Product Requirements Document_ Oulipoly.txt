A. The Reasoning Node (Gemini Vision)
Connects User Comments to SAM Masks.
import subprocess
import json
import torch
import numpy as np
from PIL import Image

class GeminiAnnotationNode:
    """
    Takes an image and a user comment.
    Uses local CLI to determine WHAT needs to be masked.
    Returns: Bounding Box [x, y, w, h] for SAM.
    """
    @classmethod
    def INPUT_TYPES(s):
        return {
            "required": {
                "image": ("IMAGE",),
                "user_comment": ("STRING", {"multiline": True}),
                "rough_select_coords": ("STRING", {"default": "0,0,1024,1024"}), # x1,y1,x2,y2
            }
        }

    RETURN_TYPES = ("BOX_COORDS", "STRING") # Coords for SAM, Adjusted Prompt for Diffusion
    FUNCTION = "analyze_comment"
    CATEGORY = "WeaveStudio"

    def analyze_comment(self, image, user_comment, rough_select_coords):
        # 1. Save temp image for CLI to see
        temp_path = "/tmp/annotation_context.png"
        self.save_image(image, temp_path)

        # 2. Construct Gemini CLI Prompt
        # We ask Gemini to act as a "Layout Engine"
        cli_prompt = (
            f"User comment: '{user_comment}'. "
            f"Rough selection box: [{rough_select_coords}]. "
            "Task: 1. Identify the precise object user wants to edit. "
            "2. Return JSON with 'bbox': [x,y,w,h] and 'stable_diffusion_prompt': 'string'."
        )

        # 3. Fire CLI (Using your system's auth)
        # Note: Replace 'gemini' with your specific CLI alias (az, aws, etc)
        cmd = f'gemini generate "{cli_prompt}" --image {temp_path} --json'
        
        result = subprocess.run(cmd, shell=True, capture_output=True, text=True)
        response_json = json.loads(result.stdout)

        # 4. Return Data
        bbox = response_json.get("bbox")
        sd_prompt = response_json.get("stable_diffusion_prompt")
        
        return (bbox, sd_prompt)

    def save_image(self, tensor, path):
        # Helper to convert Tensor to PNG on disk
        i = 255. * tensor.cpu().numpy()
        img = Image.fromarray(np.clip(i, 0, 255).astype(np.uint8)[0])
        img.save(path)

NODE_CLASS_MAPPINGS = { "GeminiAnnotation": GeminiAnnotationNode }

import subprocess
import torch
import numpy as np
from PIL import Image

class CLI_Generator:
    @classmethod
    def INPUT_TYPES(s):
        return {
            "required": {
                "command_prefix": ("STRING", {"default": "gemini generate"}),
                "prompt": ("STRING", {"multiline": True}),
                "output_filename": ("STRING", {"default": "/tmp/output.png"}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "execute_cli"
    CATEGORY = "WeaveStudio"

    def execute_cli(self, command_prefix, prompt, output_filename):
        # 1. Construct Command
        full_command = f'{command_prefix} "{prompt}" --output {output_filename}'
        
        # 2. Execute (Uses local Auth)
        subprocess.run(full_command, shell=True, check=True)
        
        # 3. Load Result
        img = Image.open(output_filename)
        img = np.array(img).astype(np.float32) / 255.0
        img = torch.from_numpy(img)[None,]
        return (img,)

NODE_CLASS_MAPPINGS = { "CLI_Generator": CLI_Generator }

Yes, you have identified a very real phenomenon known as "Recursive Instability" or "Inference Drift."
Current research confirms that repeatedly running an image through an AI generator (Stable Diffusion/Flux) causes "generational loss," similar to saving a JPEG 100 times. The image eventually becomes blurry, plastic, or overly saturated.
However, yes, there are ways to prevent this. Your "Delta Masking" algorithm is one of them, but you should combine it with Latent Cycling to make it bulletproof.
The Cause: Why do pixels get blurry?
The problem is not usually the "AI" (the Diffusion model); it is the VAE (Variational Autoencoder).
 * The Workflow: To edit an image, the system must Encode it (Pixels \rightarrow Latent Space) and then Decode it (Latent Space \rightarrow Pixels).
 * The Loss: The VAE is lossy. Every time you "Decode" to check the image and "Encode" to fix it, you lose ~2-5% of the fine texture detail. Do this 10 times in a repair loop, and the image turns to mush.
The Solutions: How to prevent it
1. "Latent Cycling" (The Pro Move)
Since the damage happens during the "Decode" step, the solution is don't decode.
 * How it works:
   * Step 1: Generate the initial image. Keep it as a Latent (do not save to PNG yet).
   * Step 2 (The Loop): The Agent detects an error.
   * Step 3 (The Fix): The Agent runs the inpaint on the Latent Data directly.
   * Step 4: Only decode to pixels when the Agent says "Final Approval".
 * Why it wins: You can run 50 repair loops in Latent Space with zero pixel degradation because you never touched the VAE.
2. Your "Delta Masking" (The Surgical Move)
Your proposed algorithm (creating a mask only for the gap) is the correct approach to stop Global Blur.
 * The Technique: Instead of feeding the whole image back into the VAE, you:
   * Crop only the error region (plus a small buffer).
   * Fix that crop.
   * Composite it back onto the original "Frozen" image.
 * The Benefit: The rest of the image (the "good" pixels) never goes through the VAE grinder again, so it stays crisp.
3. Differential Diffusion (The Soft Move)
Your PRD mentioned this , and it is a powerful anti-blur tool.
 * The Problem: Standard inpainting is "All or Nothing."
 * The Solution: Differential Diffusion allows "Soft Inpainting." You can tell the AI: "Change the structure of the car's wheel (Strength 1.0) but keep the texture of the rim (Strength 0.4)".
 * The Win: This prevents the AI from "hallucinating" new, lower-quality textures over parts of the image that were already perfect.
Summary of the "Anti-Blur" Stack
To make your "Self-Healing" feature production-ready, your pipeline should look like this:
 * Generation: Create Image (Latent).
 * Inspection: Decode a preview copy for Gemini to look at.
 * Decision: Gemini finds a gap.
 * Action: Gemini creates a Delta Mask.
 * Execution: Apply Inpaint on the Original Latent (using Differential Diffusion for blending).
 * Loop: Repeat.
 * Final: Decode once.
This workflow is mathematically immune to the "Blurry JPEG" effect.
